# Louis Van der Velden — Portfolio

Static portfolio. No build command or package installation required.

## Publish with GitHub Pages
1. Create a GitHub repository named `louis-portfolio` and push this folder.
2. In repository Settings → Pages, select Deploy from a branch, `main`, `/ (root)`.
3. GitHub supplies the public HTTPS address. A custom domain can be connected later.

## Updates
Edit the HTML, metadata or assets and push to main. GitHub Pages republishes the same public address. No rebuild in Lovable is needed.

## Local preview
Run `python -m http.server 8765` from this directory.

## Before launch
Review desktop and mobile in a browser; check video playback, filters, downloads and external links. Source and assets become public with a public repository. The thesis and CV are intentionally linked downloads.
