One family, shaped around the way we use tools.

Project
Ergonomic tool family
Year
2023
Role
Product Designer
← PreviousNext →

How can different tools feel like one family while still fitting the way each one is actually used? The project started by exploring user needs, grip and interaction, then moved through sketching, ergonomic prototypes and testing. These insights were used to refine the proportions, handle geometry and visual details into one consistent design language.

The final result is a coherent family of tools built around a shared ergonomic and visual language. Each product keeps the characteristics needed for its own use, while recurring forms, materials and details make the collection read as one recognisable system.
